# Sound effects

Every sound here is a recording; none is made by code.

`click`, `magic`, `pages-riffle` and the five `whoosh-*` files are the owner's own
picks from their curated folder, used as they are.

The rest are designs layered from recordings in the owner's licensed sound
libraries (Boom Library, Blastwave FX, Montage Whoosh Essentials), chosen by
listening (the `earshot` tools ranked each candidate against a plain description
and read every finished design for unwanted characters: pops, bells, slams,
trailer whooshes). Each was cut to one take, filtered, faded, levelled and mixed
down to a short mono file; no library recording is included whole. Levels in
`src/sound.js` were set against the click in the mix with the song.
